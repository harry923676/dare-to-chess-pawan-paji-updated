- Keep contact info visible in the UI: “Pawan Paji” and “+91 81433 95375”.
- Maintain the app’s current brand and functional layout, especially around settings, theme switching, and playable board interactions.

## Tools and workflow preferences
- Prefer reading the exact UI and styling files involved in the change before editing.
- Use minimal, targeted edits rather than broad rewrites.
- Validate with the project build or lint command after styling changes.
- Avoid needless dependency changes or unrelated feature work.
